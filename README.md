# 🛒 Campus Market (MMU Student Marketplace)

A web-based campus marketplace designed for Multimedia University (MMU) students to buy, sell, and swap items such as textbooks, electronics, clothing, and hostel groceries safely on campus.

## ✨ Features

- **Product Catalog & Categorization:** Browse items by hyperlinked categories (*Electronics, Stationery, Clothes, Fruits & Vegetables*).
- **Search & Filter:** Real-time search bar to find laptops, calculators, textbooks, and clothes instantly.
- **Hero Slider Carousel:** Interactive banner featuring highlighted campus deals and announcement slides.
- **Post an Item Modal:** Allows registered students to post new items with custom image uploads or image file paths.
- **Direct WhatsApp Chat:** Direct link on every item to message the seller on WhatsApp.
- **User Authentication Modal:** Simulated login and registration system for MMU students.
- **Local Storage Persistence:** Keeps posted items and logged-in user data saved in the browser.
